## 1. Описание проекта
Проект представляет собой командный интерпретатор (CLI), работающий в изолированной виртуальной файловой системе (VFS). VFS загружается из JSON-файла и функционирует в оперативной памяти (in-memory) без записи на физический диск. Содержимое файлов сериализовано в Base64.

## 2. Команды и формат вывода

### 2.1. `ls` (просмотр каталога)
- **Синтаксис:** `ls [путь]`
- **Вывод:** алфавитный список файлов и папок целевой или текущей директории.
- **Ошибки:** `ls: cannot access '<путь>': No such entry`

### 2.2. `cd` (переход по директориям)
- **Синтаксис:** `cd <путь>`
- **Вывод:** обновляет приглашение командной строки (поддерживает `/`, `.`, `..`).
- **Ошибки:**
  - `cd: missing argument`
  - `cd: <путь>: Not a directory`
  - `cd: <путь>: No such file or directory`

### 2.3. `cp` (копирование узлов)
- **Синтаксис:** `cp <источник> <приемник>`
- **Вывод:** дублирует узел (требует ровно 2 аргумента).
- **Ошибки:**
  - `cp: missing destination file operand`
  - `cp: cannot stat '<источник>': No such entry`

### 2.4. `tree` (дерево каталогов)
- **Синтаксис:** `tree [путь]`
- **Вывод:** рекурсивная иерархическая структура каталогов с символами `├──` и `└──`.
- **Ошибки:** `tree: cannot access '<путь>': No such file or directory`

### 2.5. `chown` (смена владельца)
- **Синтаксис:** `chown <новый_владелец> <путь>`
- **Вывод:** изменяет атрибут `owner` в метаданных узла VFS.
- **Ошибки:**
  - `chown: invalid number of arguments`
  - `chown: cannot access '<путь>': No such entry`

### 2.6. Переменные окружения и `exit`
- Подстановка переменных среды вида `$VAR` или `${VAR}` во входную строку.
- `exit` — корректный выход из сессии эмулятора.
