## 1. Описание задачи
Цель третьего этапа — реализовать программную модель виртуальной файловой системы (VFS), функционирующей в оперативной памяти без изменения реальных файлов на физическом диске. Вся структура каталогов и файлов сериализуется в формате JSON с кодированием содержимого файлов в Base64.

---

## 2. Что реализовано на 3-м этапе
1. **Модуль виртуальной файловой системы (`src/vfs.py`):**
   - Загрузка и разбор структуры VFS из JSON-образа.
   - Декодирование содержимого текстовых и бинарных файлов из Base64.
   - Построение дерева узлов (узлы типов `dir` и `file`).
   - Разрешение относительных и абсолютных путей (`resolve_parts`).
2. **Интеграция с эмулятором (`src/emulator.py`):**
   - Передача пути к файлу VFS через аргумент командной строки `--vfs`.
   - Инициализация объекта VFS при старте оболочки.
   - Формирование динамического приглашения командной строки вида `имя_vfs:/текущий_путь$ `.
