## 1. Описание задачи
Цель первого этапа — разработать архитектурный каркас программы-эмулятора командной строки.
На данном этапе не требуется подключать реальную файловую систему или выполнять прямые системные вызовы. Основная задача — организовать надежный цикл взаимодействия с пользователем (REPL), реализовать корректный разбор входной строки на аргументы и предоставить функции-заглушки для базового набора команд.

---

## 2. Что реализовано на 1-м этапе
1. **Основной цикл работы (REPL):**
   - Формирование и вывод приглашения к вводу (prompt).
   - Чтение пользовательских команд из стандартного потока ввода.
   - Корректная обработка сигналов завершения и выход по команде exit.
2. **Парсер аргументов:**
   - Токенизация входной строки: отделение имени команды от переданных параметров.
   - Обработка пробельных символов и пустых строк без аварийного завершения программы.
3. **Функции-заглушки команд:**
   - Все обязательные по заданию команды оформлены в виде отдельных обработчиков.
   - Эмулятор подтверждает вызов команды и выводит переданный список аргументов.
   - Для неподдерживаемых команд выводится информативное сообщение об ошибке.

---

## 3. Таблица поддерживаемых команд

| Команда | Назначение заглушки | Пример вызова | Поведение |
| :--- | :--- | :--- | :--- |
| ls | Список содержимого каталога | ls -la | Сообщение о вызове ls с аргументом -la |
| cd | Переход между директориями | cd /home | Сообщение о вызове cd с аргументом /home |
| cp | Копирование файлов/папок | cp file1 file2 | Сообщение о вызове cp с аргументами |
| chown | Изменение владельца узла | chown root file | Сообщение о вызове chown |
| 	ree | Древовидная структура каталогов | 	ree | Сообщение о вызове 	ree |
| exit | Завершение работы эмулятора | exit | Остановка процесса с кодом 0 |

## 5. Инструкция по запуску

Проект разработан на стандартной библиотеке Python (версия 3.10+) без использования сторонних внешних зависимостей.

### Запуск эмулятора:
\\\ash
python src/emulator.py
\\\

### Пример пользовательской сессии:
\\\	ext
$ python src/emulator.py

## 6. Модульное тестирование
Работоспособность логики этапа верифицируется с помощью встроенного модуля unittest.

### Запуск тестов:
\\\ash
python -m unittest discover tests
\\\

Тесты проверяют:
- Обработку пустого ввода.
- Корректное разбиение строки аргументов.
- Устойчивость цикла при обработке неизвестных команд.
