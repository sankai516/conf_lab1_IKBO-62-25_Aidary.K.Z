# Эмулятор командной строки (Вариант 1)

Эмулятор командной строки на языке Python для работы с виртуальной файловой системой (VFS).

## Поддерживаемые команды
- ls — просмотр содержимого директории
- cd — смена текущей директории
- cp — копирование файлов и каталогов
- chown — изменение владельца файла/папки
- tree — вывод дерева каталогов
- exit — выход из эмулятора

## Запуск
Запуск эмулятора с базовой VFS:
run.bat

## Тестирование
Запуск полного набора тестов:
scripts\run_all_tests.bat
