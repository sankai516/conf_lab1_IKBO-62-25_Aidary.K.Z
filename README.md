## 1. Описание задачи
Цель второго этапа — расширить возможности запуска эмулятора: добавить поддержку аргументов командной строки при старте программы и реализовать возможность пакетного выполнения команд из файла стартового скрипта без интерактивного участия пользователя.

---

## 2. Что реализовано на 2-м этапе
1. **Разбор аргументов командной строки запуска:**
   - Использование стандартного модуля argparse.
   - Поддержка параметра --vfs — путь к файлу виртуальной файловой системы.
   - Поддержка параметра --script — путь к текстовому файлу со списком команд для автоматического исполнения.
2. **Пакетный режим выполнения (стартовые скрипты):**
   - Построчное чтение переданного файла скрипта.
   - Игнорирование пустых строк и комментариев.
   - Последовательная передача инструкций в диспетчер эмулятора.
   - Корректное завершение работы после исполнения всех команд файла.
