## 1. Описание задачи
Цель четвертого этапа — реализовать рабочую логику базовых команд навигации и манипуляции файловой системой внутри смонтированной VFS: `ls`, `cd`, `cp`.

---

## 2. Что реализовано на 4-м этапе
1. **Команда `ls`:**
   - Отображение файлов и папок текущего каталога (если путь не передан).
   - Поддержка просмотра содержимого целевых директорий по относительному или абсолютному пути.
2. **Команда `cd`:**
   - Навигация по дереву каталогов VFS.
   - Поддержка перехода в корень (`/`), на уровень выше (`..`) и по вложенным путям.
   - Проверка существования каталога и валидация типа узла (выдача ошибки при попытке перейти в файл).
   - Автоматическое обновление пути в prompt эмулятора.
3. **Команда `cp`:**
   - Копирование содержимого исходного узла в целевой путь.
   - Валидация аргументов (ровно 2 обязательных параметра: источник и приемник).
