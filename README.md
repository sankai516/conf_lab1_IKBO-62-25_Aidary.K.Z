## 1. Описание задачи
Цель пятого этапа — реализация команд модификации виртуальной файловой системы (VFS), динамической смены образа VFS на лету, а также создание полного тестового покрытия (unit-тесты и запуск стартовых сценариев).

---

## 2. Реализованный функционал
* **`ls [путь]`** — просмотр содержимого директории (по умолчанию текущей).
* **`cd <путь>`** — переход по дереву каталогов VFS (`/`, `..`, относительные и абсолютные пути).
* **`clear`** — очистка окна терминала (кроссплатформенно: `cls` для Windows, `clear` для POSIX).
* **`tree [путь]`** — рекурсивный вывод древовидной структуры файлов и каталогов.
* **`touch <файл>`** — создание нового пустого файла по указанному пути в VFS.
* **`chown <пользователь> <объект>`** — изменение владельца файла или директории.
* **`vfs-load <путь_к_json>`** — горячая загрузка/перезагрузка нового образа VFS из JSON без перезапуска сессии.
* **`exit`** — корректное завершение работы эмулятора.
